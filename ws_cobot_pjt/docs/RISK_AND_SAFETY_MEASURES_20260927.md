## 1. 문서 역할

이 문서는 사람·로봇·공구·작업물에 위해를 줄 수 있는 위험요소와 예방·차단·복구 대책을 정리한다. 모든 소프트웨어 오류를 반복해서 나열하지 않고 관련 오류 ID를 참조한다. 코드 수정은 오류 문서에 기록하고, 안전 통제에 영향을 주는 변경만 이 문서의 대책 상태에 반영한다.

HMI의 정지 버튼은 소프트웨어 공정 정지 요청이며 물리 비상정지 장치가 아니다. 이 문서는 실제 장비의 위험성 평가, 제조사 안전 기능, 현장 감독을 대체하지 않는다.

## 4. 금지 동작

- 철사 고정 드릴 상태에서 그리퍼 자동 개방·반 열기·DO2 개방
- 실패·정지·보호정지 후 무조건 HOME 복귀
- 보호정지 자동 해제와 무조건 자동 재실행
- 힘 한계·통신 불명·정지 미확인 상태의 자동 재시도
- 미리보기와 다른 경로·프로파일 실행
- `UNKNOWN/STALE`을 정상·정지 완료로 표시
- 실제 로봇 확인 없이 깊이·속도·힘·J6 값을 승인값으로 변경
- HMI 소프트웨어 정지를 물리 비상정지로 표현

## 5. 단계별 작업자 확인

### 실행 전

- 고정 설비, 양초, 그리퍼·철사·드릴 장착 상태
- 드릴 전원 OFF, 주변 접근자와 로봇 이동 경로
- REAL 모드, 도구·TCP·load, 최신 로봇 상태
- 양초 측정 결과와 유효성
- 경로·프로파일 ID·버전·해시
- 적용 깊이·속도·contact mode와 현장 승인 상태

### 실행 중

- 현재 단계와 마지막 완료 세그먼트
- 연결·관측 freshness
- 힘·정지·알람 상태
- 드릴·양초·지그의 물리적 변화
- 작업자의 물리 비상정지 접근 가능 상태

### 오류·정지 후

- 실제 로봇이 정지했는지 현장에서 확인
- 드릴을 수동으로 OFF
- 공구·철사·그리퍼·양초·지그 상태 확인
- 현재 TCP·관절·제어권·보호정지 원인 확인
- 오류 코드와 마지막 완료 단계 기록
- 원인을 해결한 뒤 기존 run을 재개하지 않고 새 준비·측정·경로 절차 사용

## 6. 이번 코드 수정이 반영하는 안전대책

- 오류 코드·단계·운영자 조치를 HMI에 표시해 미확인 상태의 임의 재실행을 줄인다.
- 활성/해제 알람을 구분해 해제되지 않은 위험을 우선 표시한다.
- 실행 전 실제 적용 설정과 차단 사유를 읽기 전용으로 표시한다.
- REAL/SIMULATION과 관측 품질에 맞는 문구를 표시해 모의 상태를 실제 상태로 오인하지 않게 한다.
- 공정 결과와 품질 판정을 분리해 실행 완료를 품질 합격으로 오인하지 않게 한다.

이 변경은 로봇 모션·정지·힘·J6 알고리즘을 바꾸지 않으며 실제 장비 안전 검증을 완료시키지 않는다.
구체적인 수정 파일·시험 결과는 오류 문서의 `2026-09-27 코드 반영 결과`를 기준으로 하고, 이 문서에는 물리·운영 안전에 영향을 주는 효과와 잔여 위험만 남긴다.

## 7. 현장 검증 체크리스트

1. 실제 이동 중 Stop 요청 후 2초 내 정지 확인 또는 `UNKNOWN` 차단
2. 통신 단절·공정 노드 재시작 후 오래된 상태와 새 작업 차단
3. 힘 한계 초과 후 자동 재측정·복귀·다음 단계 모션이 없는지 확인
4. 고정 드릴 상태에서 초기화·종료·오류·정지 중 그리퍼 열기 명령 0건
5. J6 실제 범위·여유와 이음매 주변 경로
6. 8점 측정 반복성 및 PR #90 이후 윗면 접촉 범위
7. 정상 조각 성공 후 최신 RETURN_HOME과 실패 시 차단
8. 깊이·속도·힘 후보값과 실제 홈 깊이·형상·표면 손상
9. HMI 활성 알람·해제 이력·오류 조치가 실제 이벤트와 일치하는지 확인
